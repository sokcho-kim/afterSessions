(주)오픈메이드컨설팅, 기업 비즈니스의 핵심적 요소인, DB 구축과 안정적인 운영 및 활용을 위한 최적의 컨설팅과 솔루션을 공급하는 DB 전문 컨설팅 회사입니다. DB 성능장애 예방을 위한 SQL 성능/품질 최적화 솔루션과 함께, DB/Data 컨설팅 전문인력을 공급하여 최적의 Data 모델 설계 및 DB 이행 & SQL 성능 튜닝 및 운영 안정화 지원 등 DB 구축부터 운영까지 토탈 서비스를 제공하는 DB 전문회사로 지속 성장하고 있습니다.
(주)오픈메이드컨설팅은 데이터베이스 기술 및 솔루션 개발 분야에 특화된 전문 기술인력을 중심으로 구성되어 있으며, 20여 년간의 DB 컨설팅 영역의 경험과 노하우를 바탕으로 운영 DB 안정화를 위한 다양한 솔루션의 연구 개발에 전념하고 있음
오픈팝- SQL 품질/ 성능 최적화 지원
쿼리메딕(Query Medic)- AI 기반 SQL 자동 튜닝 솔루션
오픈팝SPS-SQL 성능 변화 분석
오픈팝OTO-ORACLE to 오픈소스 DB 전환
전시 제품 및 서비스 소개
* 오픈팝(OpenPOP)- 개발부터 운영까지 SQL 품질을 체계적으로 관리하고, 성능 변화를 분석하며, 데이터베이스 전환을 효율화
* 쿼리메딕(QueryMedic)- 다년간 축적된 SQL 튜닝 노하우에 AI 기술을 접목한 'AI 기반 SQL 튜닝 자동화' 기능을 탑재, AI 기반 SQL 자동 튜닝 솔루션, LLM을 활용한 “SQL 튜닝 자동화”로 획기적인 DB 성능 최적화 및 운영비용 절감 효과 기대. 24*365 인력개입 없이 SQL 자동으로 “추출→튜닝→검증, 인덱스 튜닝 영향도 분석까지 가능.
'Query-Medic'은 인덱스 튜닝 시 해당 테이블을 사용하는 관련 SQL의 성능 변화 영향도까지 분석하여, 성능 관리자가 인덱스 적용 여부를 신속하게 판단할 수 있도록 지원한다. 이로써 DB 성능 저하를 사전에 예방하고, 효율적인 자원 운영을 통한 비용 절감 효과를 동시에 기대할 수 있다.
