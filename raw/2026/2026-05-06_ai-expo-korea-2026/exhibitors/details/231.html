회사 및 주요 서비스 소개
㈜에이데이타는 데이터 통합 및 분석 전문 기술 기업으로 데이터 분석 분야 국내 최고 수준의 전문 기술을 통해 사회적 가치와 혁신을 실현하며, 글로벌 데이터 분석 시장을 선도하는 것을 목표로 하고 있습니다.

당사는 REST API 기반의 데이터 연계 및 통합을 위한 APIM 솔루션인 SCV와 데이터 전 처리 솔루션인 ARANGER, 데이터 분석 솔루션인 DataBoard 등을 보유하고 있으며, 데이터 관련 분야 별 전문가로 구성된 컨설팅 조직과 최신 AI 기술 접목이 가능한 전문 개발 조직을 통해 데이터 관련 분석, 설계, 구축, 관리, 유지 보수 등 원스톱 데이터 서비스를 제공하고 있습니다.
전시 제품 및 서비스 소개
SCV™ - 지능형 데이터 연계·표준 솔루션 (Smart Collection Vehicle)

REST API 기반의 데이터 수집 및 연계 과정에서 전문 연계 개발 인력의 투입을 필요로 하던 종래의 기술적 한계를 극복하여 데이터 수집ˑ적재 과정의 자동화 및 API 를 통한 데이터 연계를 위한 대량의 API 를 효율적으로 생성하고 관리하여 비용 절감, 운영 효율성을 획기적으로 강화한 No Code 기반의 APIM 솔루션

[주요 특징]

〇 No-Code
- 직접적인 코딩 없이 간단한 UI/UX 작업으로 다양한 API 데이터 연계/수집

〇 데이터 병렬처리
- 데이터 수집 병렬 처리(Parallel processing) 기능 지원으로 수집 성능 향상

〇 데이터 저장 자동화
- AI 기반 데이터 자동 분류 및 프로파일링을 통한 Target DB 저장 자동화 지원

〇 확장성
- API, DB, File, Web 등 다양한 수집 대상 추가 가능

〇 API 생성 및 관리 용이성
- API 신규 생성 및 관리, API 스펙 정의, API 승인, 게시 및 모니터링
- 수집 대상, 현황, 데이터 등의 현황 정보를 한눈에 확인 가능하도록 통합 대시 보드 제공
제품별 적용 분야 및 실제 적용 사례
SCV 는 REST API 를 활용한 데이터 연계 수집은 물론 APIM 기능을 통합한 노 코드 기반 솔루션으로 다양한 사이트에서 개발 기간 단축, 비용 절감 효과를 입증하고 있습니다.

- 농림수산식품 교육문화정보원의 귀농귀촌통합플랫폼 구축사업 中 데이터 수집·적재 자동화를 위해, 데이터 연계 기술을 적용하여 인건비 75%절감, 수집완료 기간 50%단축, 관리 효율성의 극대화 등 혁신적인 성과를 달성

- 국제청 법령 정보시스템 구축 사업을 통한 제품 성능 입증, 법제처 법령 정보 16종 연계/수집 완료(총 16종 목록 60만 건, 본문 1200만 건의 데이터 연계/수집), 효율성 및 운영 효율성 입증

그 외에도 공영홈쇼핑, 한국고용노동교육원 등에서 API 기반 데이터 연계 및 APIM 솔루션으로 선정되어 프로젝트를 수행하고 있습니다.
