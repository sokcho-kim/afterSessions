PROST Inc.

AI Solution
카테고리

· Text/Voice/Image/Video application
· Conversation AI
https://prost.team
충남 천안시 서북구 2공단1로 17 (성성동) 자이타워 본동 1026호
회사 및 주요 서비스 소개
주식회사 프로스트는 공공기관 및 대학 정보시스템 구축·운영 경험을 기반으로 AI 기반 AX(AI Transformation) 통합 플랫폼을 개발·공급하는 전문 기업입니다.

ERP/EIP/BPM 구축 및 유지 운영, LMS/CMS 구축, 통합 배치 솔루션(Job-Sync), 모바일 그룹웨어 등 실 운영 시스템을 직접 설계·개발·운영해 온 기술 조직으로, 최근에는 RAG 기반 AI 챗봇 및 멀티 LLM 연계 플랫폼을 자체 기술로 구현하였습니다.

특히 온프레미스 및 하이브리드 환경에서 운영 가능한 공공·대학 맞춤형 AI 아키텍처를 강점으로 하며, 기존 행정시스템과의 API 기반 연계를 통해 실질적인 업무 자동화 및 지능화를 지원합니다.
전시 제품 및 서비스 소개
1. RAG 기반 지능형 챗봇 플랫폼 (Pro AX-Platform)

공공·대학 환경에 최적화된 RAG(Retrieval-Augmented Generation) 기반 지능형 챗봇 플랫폼입니다.
기관 내부 문서, 규정, 학사 자료, 매뉴얼 등을 기반으로 정확도 높은 응답을 제공합니다.

주요 특징
ㆍ자체 OCR 엔진 적용→ 스캔 PDF, 이미지, 동영상 자막 등 비정형 문서 99% 이상 텍스트 추출
ㆍ아래아한글(HWP) 문서 직접 처리 및 벡터화 지원
ㆍVector DB 기반 고속 검색 및 문맥 기반 응답 생성
ㆍ온프레미스 및 하이브리드 구축 지원
ㆍ사용자/권한/로그 통합 관리 기능 제공

기존 키워드 검색 방식이 아닌 의미 기반 검색과 생성형 AI 응답을 결합한 구조로, 내부 문서 활용도를 획기적으로 향상시킵니다.

2. AI 기능 확장형 LMS 플랫폼 (Pro LX-Flow)

기존 LMS에 생성형 AI 기술을 접목하여 학습 지원과 행정 지원을 동시에 제공하는 차세대 학습 플랫폼입니다.

주요 기능
ㆍ강의자료 기반 AI 학습 튜터 기능
ㆍ과제·시험 관련 질의 자동 응답
ㆍ학습 성과 분석 및 맞춤형 콘텐츠 추천
ㆍ멀티 LLM 선택 구조(OpenAI, Gemini, Claude, LLaMA 등 연계 가능)
ㆍAPI 기반 학사행정 시스템 연계

단순 학습관리 시스템을 넘어, AI 기반 학습 지원 플랫폼으로 확장 가능한 구조를 제공합니다.
제품별 적용 분야 및 실제 적용 사례
1. 백석문화대학교 AX 시스템 구축 사업
대학 행정 및 학습 환경의 AI 전환을 목표로 AX 통합 시스템을 구축하였습니다.

주요 구축 내용
ㆍ통합 관리 지식 저장소 구축
→ 교내 규정, 행정문서, 업무자료 통합 벡터화 및 검색 체계 구현
ㆍRAG 기반 AI 챗봇 도입
→ 내부 문서 기반 질의응답 자동화
ㆍ결재 문서 자동 생성 기능 구현
→ AI 기반 초안 생성 및 업무 생산성 향상
ㆍ업무 협업 기능 구축
→ 조직 단위 협업 및 이력 관리 기능 제공
ㆍLMS 고도화 및 AI 기능 확장
→ 학습자료 기반 AI 튜터 기능 적용
→ 학습 지원 자동 응답 기능 구현


2. 한국기술교육대학교 RAG 챗봇 연구 사업 및 납품
대학 내부 시스템 환경에 최적화된 RAG 기반 AI 챗봇 플랫폼을 연구·개발 및 납품하였습니다.
폐쇄적 인프라 환경을 고려한 데이터 수집·운영 구조를 설계하였습니다.

주요 구축 내용
ㆍ폐쇄형 환경 대응 데이터 인제스천 체계 구축
→ 크롤링 기반 데이터 수집 및 벡터화 자동화
ㆍ챗봇 빌더 기반 중앙 통합 관리
→ 챗봇 생성, 배포, 버전 관리 기능 제공
ㆍ멀티 LLM 선택 구조
→ OpenAI, Gemini, Claude, LLaMA 등 사용자 선택형 모델 운영 지원
ㆍ다양한 데이터 소스 연계 지원
→ 웹 크롤링, 문서 파일(PDF/HWP 등), DB 동기화 기반 지식 베이스 구축
ㆍ사용자 개인별 페르소나 구성 기능
→ 대화 이력 기반 개인화 응답
→ 사용자 지정 프롬프트 설정 기능
ㆍ세션·사용자 단위 사용량 모니터링
→ 토큰 사용량 및 비용 실시간 확인
ㆍMCP(Model Context Protocol) 기반 외부 시스템 연계 구조
→ 행정시스템, LMS, 포털 등과 API 연동 가능
→ 향후 기능 확장 및 AI 서비스 고도화에 유연한 구조 제공
